# library: Keshav's cross-project knowledge

Scouts search this **before** the internet: your own past decisions and lessons beat a random blog.

| Folder | What goes in | Written by |
|--------|--------------|-----------|
| `patterns/` | reusable designs that worked (or failed): one file per pattern, with where it was used | you, `/retro` |
| `playbooks/` | step-by-step procedures (incident response, release, onboarding a stack) | you |
| `stacks/` | per-tech notes: gotchas, versions, flags, the commands that matter | you, scouts |
| `papers/` | paper notes: claim, setup, numbers, what transfers to us | `/research` |
| `research/` | `/research` outputs, dated | synthesizer |
| `council/` | `/council` records, dated | chairman |
| `evolve-log.md` | every `/evolve` cycle: mechanism, edit, verdict | `/evolve` |

Rules: dated, sourced, short. When a note is wrong now, mark it `superseded` and link the
replacement. Don't delete history.
